Pump room specifications

Send us your pump room specifications

Use this guide if you are submitting by email instead of the Engineer Portal.

What we need

1
Pump Room IDName or number each pump room and note where it is in the building.
2
Pool assignmentsThe pools and spas each pump room serves, with volume and water type.
3
Return line specificationsFor each pool: every return line, its pipe size, flow, material and straight run.
